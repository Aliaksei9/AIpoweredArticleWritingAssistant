# Оценка соответствия паттернам популярности по социальным метрикам

`AssesmentConformPPmetricsBased` принимает просмотры V, реакции R, комментарии C
и аудиторию A. Версия формулы — `log-activity-v3`.

## Допустимые данные

- V > 0, A > 0: нулевые просмотры и аудитория не являются низкой популярностью, это некорректные данные.
- R >= 0, C >= 0: отсутствие реакций или комментариев допустимо.
- None означает отсутствие известного значения; отрицательные значения, NaN и бесконечности отклоняются.

При нулевых V/A или неизвестном входе `assess()` возвращает None, в БД оценка — NULL.
Коллектор пропускает статьи с неполными метриками, неположительными просмотрами или
аудиторией до векторизации. Нулевые реакции и комментарии сохраняются.

## Формула

Сначала вычисляется общий показатель активности:

```text
qv = V / (0.10 * A)
qr = R / (0.0008 * A)
qc = C / (0.00005 * A)

P = 0.20 * ln(1 + qv)
  + 0.40 * ln(1 + qr)
  + 0.40 * ln(1 + qc)

score = 10 * tanh(ln(P / ln(2)) / temperature)
temperature = 1.5
```

При V > 0 показатель P всегда положителен. Нули R/C дают нулевой вклад в P,
а не фиксированный штраф по четыре балла. Ограничение tanh применяется к общему
показателю после объединения метрик. Поэтому отсутствие комментариев больше
не ограничивает оценку сверху двумя баллами при сильных просмотрах и реакциях.

Реакции и комментарии имеют веса по 40%, просмотры — 20%. ln(1+q) сглаживает
выбросы; опорные доли задают сопоставимый масштаб разных метрик. Оценка растёт
с каждой метрикой и сохраняется при пропорциональном изменении всех счётчиков
и аудитории. Увеличение temperature делает шкалу мягче.

Когда все метрики достигают опорных долей, P = ln(2), поэтому оценка равна нулю.
Для A = 100000 опорный набор — V = 10000, R = 80, C = 5. Отрицательная оценка
означает, что общий показатель ниже опорного; это не отрицательные исходные счётчики.
Границы -10/+10 являются пределами преобразования, а не значениями для искусственного
случая с нулевыми просмотрами. Достигать обеих границ в реальной выборке не требуется.

В коде расчёт выполняется через логарифмы и log-sum-exp без формирования огромных
или слишком малых промежуточных отношений. Результат округляется до шести знаков.

## Проверка на данных

На снимке 2415 статей нулевых просмотров, реакций и аудитории нет, но у 748 статей
нет комментариев. Исключение таких комментариев удалило бы около 31% корректных
примеров. Сравнение формул находится в `model_tests/results/metric_formula_v3_20261023/`:
новые оценки от -9.002671 до 7.987024, медиана 0.375366. Эти числа относятся к этому
снимку и не являются ограничениями формулы.

Опоры 10% / 0.08% / 0.005% остались исходной настройкой по данным Jeteed, а не
универсальной нормой для любой платформы. Они не подстраиваются под каждый запрос.

## БД и обучение

Модуль оценки выполняет только расчёт `assess()` и проверку его входных данных.
Чтение записей и сохранение новых оценок выполняет
`ArticleMetricTable.recalculate_scores()` в модуле БД. Пересчёт проходит в одной
транзакции с блокировкой выбранных строк: ошибка откатывает все изменения,
а параллельное обновление метрик не подменяет исходные значения во время расчёта.
При `ArticleMetricTable.upsert` оценка также пересчитывается.
Используется снимок `article_metrics.audience`, а не текущая аудитория ресурса.

После изменения формулы необходимо пересчитать целевые значения и обучить
согласованную пару модулей 3/4:

```powershell
.\.venv312\Scripts\python.exe -m src.database init-db
.\.venv312\Scripts\python.exe -m src.social_metrics_prediction train
```

При этом метрики, тексты, UUID и векторы статей сохраняются. Пересчитывается
`popularity_pattern_score`, а обученные модели заменяются новыми артефактами.
Исторические отчёты сравнения моделей относятся к прежней версии целевых оценок.

```powershell
.\.venv312\Scripts\python.exe -m unittest model_tests.test_assessment model_tests.test_collection -v
.\.venv312\Scripts\python.exe -m model_tests.compare_metric_formulas --output model_tests/results/new_formula_comparison
```

Вторая команда читает БД, сохраняет статистику и график; оценки в БД не изменяет.
