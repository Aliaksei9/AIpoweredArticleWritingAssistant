# Модуль прогнозирования социальных метрик

`SocialMetricsPredictor` возвращает просмотры, реакции и комментарии. Каждая метрика имеет собственную модель и параметры, выбранные по её MSE.

Расширенный вход: тема, **прогнозная** оценка модуля 3, ресурс и тип источника, аудитория, эмбеддинг полного текста и дата публикации. Прогноз всегда рассчитывается **на 7-й день после публикации**, срок задавать не нужно. Счётчики самой прогнозируемой статьи в признаки не входят. Для модуля 3 по-прежнему нужны только текст и тема.

Все три модели получают одну и ту же полную матрицу признаков из `UnifiedFeatureEncoder`. [Общие входы, хранение и ограничения](../../docs/unified_social_inputs.md).

Для реакций выполняется отдельный более подробный подбор на трёх внутренних групповых разбиениях: 3000 сочетаний параметров, выбор по MSE только реакций. На всех 11740 статьях снижение MSE относительно среднего канала выросло с 0.89% до 1.57%; просмотры и комментарии сохранены. [Парное сравнение](../../docs/experiments/2026-11-12-reactions/README.md).

## Обучение и прогноз

Команды выполняются из корня проекта:

```powershell
python -m src.database init-db
python -m src.social_metrics_prediction train
python -m src.social_metrics_prediction resources
python -m src.social_metrics_prediction predict --topic 'Игры' --text-file model_tests/example_article.txt --resource 'Jeteed' --source TG --published-at '2026-11-13T18:00:00+03:00'
```

Ресурс задаётся UUID либо точным названием из `resources`. При одинаковых названиях используйте UUID. По умолчанию каталог и аудитория читаются из PostgreSQL; `--offline-resources` использует снимок в артефакте. Дата с часовым поясом необязательна: пустое значение означает сейчас. Срок фиксирован — семь дней.

Расширенной модели нужен `--text-file`. Старые артефакты прежнего формата по-прежнему поддерживают `--score`. Вектор текста разделяется с модулем 3, повторная векторизация не нужна.

`train` по умолчанию использует `--feature-mode unified --text-strategy additive_ensemble`. Данные читаются через классы модуля БД из актуальных таблиц. Каждая статья имеет одну метку из последних метрик. Модуль 4 обучается на прогнозных оценках вне обучающих групп (cross-fitting). Точные повторы текстов не пересекаются между частями разбиения.

Параметры: `--output`, `--text-model-file`, `--folds`, `--threads`, `--seed`. Прежнюю схему можно обучить с `--feature-mode legacy --text-strategy standard`. Время обучения не участвует в выборе моделей.

Артефакты: `artifacts/social_metrics/model.joblib` и `artifacts/text_models/neural_network.joblib`. SHA256 текстовой сети записывается в метаданные социальной модели. При несовпадении пары прогноз отклоняется. `model.training.json` содержит локальный протокол разбиений и обучения. После изменения эмбеддингов, формулы целевой оценки или отдельного переобучения текстовой сети переобучите согласованную пару.

## Python API

```python
from src.social_metrics_prediction import SocialMetricsPredictor
from src.assesment_conform_of_PP_text_based import AssesmentConformPPtextBased

text_model = AssesmentConformPPtextBased.load("artifacts/text_models/neural_network.joblib")
model = SocialMetricsPredictor.load("artifacts/social_metrics/model.joblib")
text, topic = "Текст публикации.", "Игры"
vector = text_model.encoder.embedder.embed_document(text)
score = float(text_model.model.predict(text_model.encoder.transform([text], [topic], [vector]))[0])
result = model.predict(topic, score, "Jeteed", "TG", document_embedding=vector,
                       published_at="2026-11-13T18:00:00+03:00")
print(result.to_dict())
```

Низкоуровневый `fit(rows, counts, document_embeddings=..., groups=...)` принимает уже подготовленные прогнозные оценки. Полный процесс реализован в `train`. Исследовательский `predict_rows(rows, document_embeddings=...)` использует внутренние даты и возраст счётчиков в строках; результат — матрица `(n, 3)` в порядке просмотры, реакции, комментарии. Пользовательский `predict` сам подставляет семь дней. Фактический возраст обучающих счётчиков 2–14 дней сохраняется, веса совместимы. Загружайте собственные доверенные joblib-файлы.

## Исследования и ограничения

Эксперименты находятся вне `src`, в `model_tests`. Полная проверка расширенной цепочки: `python -m model_tests.validate_unified_metrics --database-only --output model_tests/results/my_validation`. Отдельный `model_tests.train_unified_pair` готовит итоговую пару в заданном каталоге, не заменяя рабочие веса. Оценка проводится по каждому исходному счётчику относительно арифметического среднего канала. Цель — снижение MSE минимум на 2% отдельно по каждой метрике, прогретый ответ до 10 секунд.

Точность на старых разбиениях не доказывает качество на новых датах. В обучении используется одна актуальная запись на статью; прогноз на конкретный день предварительный. Исторические исследования и прежние модели сохранены в [docs/experiments](../../docs/experiments); результаты разных корпусов напрямую не сравниваются.

Источник — общее строковое поле. Сейчас представлены только данные `TG`. Для VK/X нужны сборщик, данные и переобучение. Неизвестный тип явно отклоняется. Для нового канала TG необходим `ResourceInfo` с аудиторией; качество на новых каналах отдельно не подтверждено.
