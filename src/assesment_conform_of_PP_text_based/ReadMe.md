# Оценка соответствия паттернам популярности по тексту

В рабочем модуле оставлена **только выбранная нейронная сеть** `NeuralNetworkModel`. Градиентный бустинг, случайный лес и CatBoost перенесены в `model_tests/text_candidates.py`. Старые эксперименты и их сохранённые модели доступны через `ExperimentalTextAssessment.load()` из этого файла.

Команда обучения по умолчанию использует `--strategy additive_ensemble`: отдельную ветвь текста/темы и две MLP с усреднением прогнозов. Реализация находится в `ensemble.py`. `--strategy standard` обучает прежнюю одиночную сеть из `neural_network.py`. `NeuralNetworkModel` сохраняет общий интерфейс артефактов.

Обучение читает актуальные статьи: одна статья и одна метка из последних метрик. Точные повторы текста объединяются при проверке. [Общие входы и совместное обучение](../../docs/unified_social_inputs.md).

## Вход и выход

Обучение: текст, тема и целевая оценка модуля 2. Прогноз: текст и тема. Социальные метрики и аудитория не входят в признаки.

```text
Полный текст → замороженная SBERT/E5 → 384 числа
Тема → E5 с префиксом «Тема статьи: …» → 384 числа
                         ↓
StandardScaler → MLP 768 → 256 → 128 → 1 → 10 × tanh
                         ↓
             оценка в диапазоне [-10, 10]
```

`intfloat/multilingual-e5-small` используется через общий `TextEmbedder` из модуля БД. Длинные тексты обрабатываются частями. Веса E5 заморожены; эмбеддинги тем кэшируются. После подбора конфигураций обучается только MLP: CPU, 60 эпох, AdamW, MSE, batch size 128, шаг 0.0005, weight decay 0.1, Dropout 0.5. Scaler обучается только на обучающей части и сохраняется с весами сети. В прогнозе Dropout выключен.

## Запуск из корня проекта

```powershell
# Переобучение нейросети на всех размеченных статьях БД
.\.venv312\Scripts\python.exe -m src.assesment_conform_of_PP_text_based train

# Прогноз по текстовому файлу
.\.venv312\Scripts\python.exe -m src.assesment_conform_of_PP_text_based predict --model-file artifacts/text_models/neural_network.joblib --text-file model_tests/example_article.txt --topic 'Технологии'
```

В рабочем модуле всегда обучается нейронная сеть; параметр `--model` удалён. Другие модели доступны только в `model_tests`. `--output` меняет каталог артефактов; по умолчанию `artifacts/text_models`. `--refresh-scores` пересчитывает целевые оценки через модуль БД перед обучением. `--reembed` заново вычисляет признаки текстов настроенной моделью эмбеддингов локально, без записи в БД. Сохранённые в БД векторы перед обучением проверяются на совместимость. Неизвестные или чужие векторы нужно предварительно пересчитать командой `python -m src.database reembed`.

```python
from src.assesment_conform_of_PP_text_based import AssesmentConformPPtextBased

assessor = AssesmentConformPPtextBased()
assessor.train(texts, topics, metric_scores)
assessor.save("artifacts/text_models/neural_network.joblib")
loaded = AssesmentConformPPtextBased.load("artifacts/text_models/neural_network.joblib")
score = loaded.assess("Текст новой статьи", "Игры")
```

Артефакт хранит scaler, веса MLP, кэш тем, версии признаков, E5 и формулы метрик. Веса E5 не дублируются. Перед использованием загрузите `.env`, чтобы применить проектный `HF_HOME`. Загружайте собственные доверенные joblib-файлы.

Данные читаются через `ArticleTextTable.list_training_data()`. Целевая оценка проверяется по снимку аудитории `article_metrics.audience`; неизвестные метрики, нулевые просмотры и нулевая аудитория исключают целевую оценку. Известные нули реакций и комментариев допустимы. Модуль не перезаписывает оценки в БД своими прогнозами. При загрузке проверяются настроенный профиль эмбеддингов и версия целевой формулы: старый артефакт нужно переобучить после пересчёта БД.

## Связь с модулем 4

`src.social_metrics_prediction train` обучает согласованную пару: эту нейросеть на всех данных и выбранную модель социальных метрик на её прогнозах вне обучающих групп (cross-fitting). Для последовательного прогноза используйте эту команду после обновления БД. Она сохраняет SHA256 нейросети в метаданных модуля 4. Отдельное переобучение модуля 3 требует переобучить и модуль 4.

## Результаты выбора

Исторический результат дополнительного подбора 11.11.2026: конфигурация `wide_60`: MSE прежней отложенной части **9,7868**, RMSE **3,1284 балла**, вместо MSE 10,3668. Вход не изменён: только текст и тема. Рабочие веса обучены на 8143 строках; 2039 прежних контрольных строк и все дополнительные тексты исключены из обучения этой сети. [Новый отчёт](../../docs/experiments/2026-11-11-tuning/README.md).

Первое сравнение до подбора конфигураций:

11.11.2026 на 10 182 статьях нейросеть получила MSE CV 11,0793 и MSE отложенной проверки 10,3668 (RMSE 3,2197 балла). Все четыре семейства удовлетворяют пределу измеренного ответа с E5 до 10 секунд; нейросеть выбрана по минимальной CV MSE. Время обучения не учитывается. Рабочая пара затем обучена на всей выборке. [Таблицы и графики](../../docs/experiments/2026-11-11/README.md). Команда сравнения: `python -m model_tests.compare_text_models --max-response-seconds 10`. Прежние результаты на 2415 статьях с другой версией целевой формулы сохранены локально как исторические; напрямую сравнивать ошибки разных формул нельзя.

Оценка является прогнозом эвристической формулы модуля 2. Разделение по группам одинаковых текстов проверяет имеющиеся каналы; оно не измеряет качество будущих дат и новых ресурсов.

## Выбор модели эмбеддингов

Схемы с размерами 384/768 описывают профиль по умолчанию. При другой размерности вход текстовой сети равен двум размерам эмбеддинга. [Конфигурация, миграция и совместимость](../../docs/embedding_configuration.md).
