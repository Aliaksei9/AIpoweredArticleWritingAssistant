# Готовая пара прогнозных моделей

В репозиторий включены только два небольших файла, необходимых для прогноза:

| Файл | Назначение |
| --- | --- |
| `text_models/neural_network.joblib` | Прогноз оценки по тексту и теме, PyTorch MLP |
| `social_metrics/model.joblib` | Прогноз трёх метрик, три MLPRegressor и каталог ресурсов |

Пара обучена 23 октября 2026 года на 2415 размеченных статьях из 24 Telegram-ресурсов.
Версия оценки: `log-activity-v3`. Контрольные суммы и сведения о подготовке записаны
в [`model_bundle.json`](model_bundle.json). Модуль 4 также хранит SHA-256 связанного
текстового файла; контроллер проверяет его при запуске.

Это артефакты обучения на всей пригодной выборке, а не отчёт независимой проверки.
Исходные посты, дамп БД, исторические результаты, промежуточные модели и наборы
признаков сюда не включены. Каталог ресурсов содержит публичные названия,
идентификаторы и аудитории на момент подготовки; эти значения могут устаревать.

Веса `intfloat/multilingual-e5-small` скачиваются отдельно через Hugging Face;
они не встроены в `.joblib` и не публикуются в этой папке.

Для обучения новой согласованной пары выполните из корня проекта:

```powershell
.\.venv312\Scripts\python.exe -m src.social_metrics_prediction train
```

Команда заменит рабочие файлы и создаст локальный `model.training.json` с протоколом.
Переобучение только текстовой модели требует последующего переобучения модуля 4.
Перед заменой сохраните нужную старую пару. После замены перезапустите редактор.

`.gitignore` исключает все новые выходы `artifacts/`, кроме этих двух файлов,
этого README и `model_bundle.json`. Код всех альтернативных моделей расположен
в `model_tests/` и включён в репозиторий.

Используйте только доверенные файлы `joblib`: загрузка этого формата выполняет
десериализацию Python-объектов. Подробный запуск и версии — в [главном README](../README.md).
