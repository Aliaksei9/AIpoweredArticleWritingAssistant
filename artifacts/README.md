# Готовая пара моделей: общий набор входов

В пакет включены `text_models/neural_network.joblib` и `social_metrics/model.joblib`. Контрольные суммы, размеры и настройки — в [model_bundle.json](model_bundle.json).

Модуль 3 получает текст и тему. Три модели модуля 4 получают одну и ту же полную матрицу: вектор текста, тему, прогнозную оценку популярности, ресурс и его тип, аудиторию, время публикации. Пользовательский срок прогноза удалён: **всегда семь дней после публикации**. Во внутреннюю матрицу подставляется постоянный возраст 7, чтобы сохранить совместимость весов; при обучении остаётся фактический возраст счётчиков. Метрики прогнозируются независимыми моделями с разными обученными параметрами.

Пара обучена на 11740 уникальных статьях, по одной последней записи на ID. Повторные замеры удалены из БД и обучения. В текущей БД остаётся пять исходных таблиц. Время последнего сбора сохраняется вместе с последними счётчиками.

На одинаковых статьях, разбиениях и прогнозах текста отдельно улучшена модель реакций: её выигрыш относительно среднего канала вырос с 0.89% до 1.57%. Модели просмотров, комментариев и текстовая сеть сохранены. Итоговое снижение MSE относительно среднего канала составляет 12.66% / 1.57% / 1.93%. Цель 1% для реакций достигнута; цель 2% пока не достигнута для реакций и комментариев. [Полный отчёт и графики](../docs/experiments/2026-11-12-reactions/README.md).

Веса дообучены на всём корпусе после групповой проверки; это проверка процедуры, а не ошибка на обучающих строках. Нужен отдельный контроль будущих дат. 1527 старых дополнительных статей имеют время сбора партии. Исходные посты, матрицы признаков, промежуточные модели и дампы не публикуются. SBERT скачивается отдельно; профиль проверяется при загрузке.

```powershell
python -m src.database init-db
python -m model_tests.validate_unified_metrics --database-only --output model_tests/results/my_unique_validation
python -m src.social_metrics_prediction train
```

Обычный `train` использует актуальные статьи собственной БД и не воспроизводит этот исторический корпус побитно. После изменения формулы оценки или эмбеддингов переобучите обе модели. SHA256 текстовой сети проверяется социальной моделью. После замены файлов перезапустите UI. Используйте доверенные joblib-файлы.
