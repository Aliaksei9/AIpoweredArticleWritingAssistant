# Смена модели эмбеддингов

Модель выбирается в `.env` и применяется после перезапуска Python-процесса. По умолчанию сохранена совместимость с поставляемыми весами:

```dotenv
EMBEDDING_MODEL=intfloat/multilingual-e5-small
EMBEDDING_DIMENSIONS=384
EMBEDDING_DOCUMENT_PREFIX=passage
EMBEDDING_QUERY_PREFIX=query
```

`EMBEDDING_MODEL` — идентификатор модели Sentence Transformers/Hugging Face или путь к локальной модели. `EMBEDDING_DIMENSIONS` должен совпадать с её реальным выходным размером. Если размер не совпадает, загрузка завершится понятной ошибкой. Префиксы указываются без `: `; для моделей, которым они не нужны, задайте пустые значения:

```dotenv
EMBEDDING_DOCUMENT_PREFIX=
EMBEDDING_QUERY_PREFIX=
```

После изменения модели, размерности или префиксов выполните из корня проекта:

```powershell
.\.venv312\Scripts\python.exe -m src.database reembed
.\.venv312\Scripts\python.exe -m src.social_metrics_prediction train
```

Первая команда обновляет схему и пересчитывает все векторы, сохраняя тексты, источники и социальные метрики. Вторая обучает согласованную прогнозную пару. Затем перезапустите редактор. Перед заменой используемых весов сравните кандидата на всей выборке; новый эмбеддер сам по себе не гарантирует улучшения прогнозов.

В БД используется `vector` без фиксированной размерности SQL. Размер вектора проверяется в Python. Запись содержит профиль пространства: модель, размерность, префиксы. При смене префиксов или размерности меняется отпечаток профиля, поэтому векторы одинаковой длины из разных пространств не смешиваются. Неизвестные старые векторы требуют полного пересчёта, а не присвоения им метки модели.

Артефакт текстовой сети сохраняет профиль и размер входа `2 × EMBEDDING_DIMENSIONS`. Несовместимые веса отклоняются. Смена `.env` во время работы сервера не переключает уже загруженные модели: необходим перезапуск.

Исторические исследовательские `.npz` в проекте относятся к прежнему E5-профилю. Для нового эмбеддера нужно заново получить признаки и повторить полную проверку; старые результаты качества к нему не относятся.
