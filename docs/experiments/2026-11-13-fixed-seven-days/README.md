# Фиксированный прогноз на семь дней — 13.11.2026

Прогноз просмотров, реакций и комментариев всегда рассчитывается на 7-й день после публикации. Выбор срока удалён из UI, API, контроллера, Python-метода `predict` и CLI. В интерфейсе это указано в заголовке и подписи прогноза. Сохранённый в старом черновике срок не используется. API отклоняет удалённое поле `horizon_days`.

Перед изменением сохранены прогнозы всех 11740 уникальных статей при сроке семь дней. После изменения все три прогноза совпали на каждой строке; SHA256 социальных весов сохранён. Это полная проверка эквивалентности прежнему семидневному режиму, а не новая оценка точности на седьмой день: фактические счётчики корпуса получены в возрасте 2–14 дней. Веса и фактический возраст обучающих счётчиков не менялись.

Время публикации остаётся необязательным входом. Для совместимости обученной матрицы внутренний возраст прогноза фиксируется значением 7. В ответе API остаются `forecast.horizon_days: 7`, `forecast.fixed_horizon: true` и дата прогноза `forecast_at` — время публикации плюс семь суток.

Проверки: 189 Python-тестов и 17 тестов JavaScript; сценарий полной проверки — `model_tests/verify_fixed_seven_days.py`. Исходная выборка и промежуточные прогнозы остаются локальными, вне GitHub.

Реальный полный запрос API без срока прогноза проверен с SBERT и тремя моделями. Максимальный прогретый ответ — 3.138 с, в том числе на текстах длиной 50 000 символов.
